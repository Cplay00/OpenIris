# 修复报告：截图保存失败（P0）

## 日期
2026-06-17

## 问题描述
Android 10+ (API 29+) 引入 Scoped Storage，废弃了直接使用 `File` API 写公共目录的方式。原有 `saveBitmap()` 方法使用 `getExternalFilesDir()` 或传统 File API 保存截图到公共 Pictures 目录，在 Android 10+ 设备上保存失败。

## 涉及文件
- `buildapk/app/src/main/java/com/yolo/openiris/RealtimeDetectActivity.kt`

## 修改内容

### 1. `saveBitmap()` 方法（行 348-390）

**修改前：**
```kotlin
private fun saveBitmap(bitmap: Bitmap) {
    // ... 仅使用 File API，无 Scoped Storage 兼容
    val configPath = configManager.getImageExportPath()
    val baseDir = getExternalFilesDir(Environment.DIRECTORY_PICTURES) ?: filesDir
    // ...
    file.outputStream().use { out ->
        bitmap.compress(Bitmap.CompressFormat.JPEG, 95, out)
    }
}
```

**修改后：**
```kotlin
private fun saveBitmap(bitmap: Bitmap): Boolean {
    val timeStamp = SimpleDateFormat("yyyyMMdd_HHmmss", Locale.getDefault()).format(Date())
    val fileName = "OpenIris_${timeStamp}.jpg"

    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
        // Android 10+ 使用 MediaStore API 保存到公共相册
        val contentValues = android.content.ContentValues().apply {
            put(android.provider.MediaStore.Images.Media.DISPLAY_NAME, fileName)
            put(android.provider.MediaStore.Images.Media.MIME_TYPE, "image/jpeg")
            put(android.provider.MediaStore.Images.Media.RELATIVE_PATH, "Pictures/OpenIris")
        }
        val uri = contentResolver.insert(
            android.provider.MediaStore.Images.Media.EXTERNAL_CONTENT_URI, contentValues
        )
        if (uri != null) {
            contentResolver.openOutputStream(uri)?.use { out ->
                bitmap.compress(Bitmap.CompressFormat.JPEG, 95, out)
            }
            return true
        } else {
            return false
        }
    } else {
        // Android 9 及以下使用传统文件 API
        if (ContextCompat.checkSelfPermission(this, Manifest.permission.WRITE_EXTERNAL_STORAGE)
            != PackageManager.PERMISSION_GRANTED) {
            Toast.makeText(this, "缺少写入存储权限，无法保存截图", Toast.LENGTH_SHORT).show()
            return false
        }
        val storageDir = Environment.getExternalStoragePublicDirectory(Environment.DIRECTORY_PICTURES)
            .let { File(it, "OpenIris").apply { mkdirs() } }
        val file = File(storageDir, fileName)
        file.outputStream().use { out ->
            bitmap.compress(Bitmap.CompressFormat.JPEG, 95, out)
        }
        return true
    }
}
```

### 2. 调用处（行 298、306）

**修改前：**
```kotlin
saveBitmap(annotatedBitmap)
// ...
Toast.makeText(this, "截图已保存", Toast.LENGTH_SHORT).show()
```

**修改后：**
```kotlin
val saved = saveBitmap(annotatedBitmap)
// ...
if (saved) Toast.makeText(this, "截图已保存", Toast.LENGTH_SHORT).show()
```

## 关键变更点

| 项目 | 说明 |
|------|------|
| MediaStore API | Android 10+ 通过 `ContentResolver` + `MediaStore` 写入 `Pictures/OpenIris`，无需存储权限 |
| 向下兼容 | Android 9 及以下继续使用 `File` API + `WRITE_EXTERNAL_STORAGE` 权限 |
| 返回值 | `saveBitmap` 改为返回 `Boolean`，调用方根据结果决定是否显示 Toast |
| 文件编码 | 移除 UTF-8 BOM（项目规范要求 no-BOM UTF-8） |
