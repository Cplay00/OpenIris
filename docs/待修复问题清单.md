## 待修复问题清单

### 板块二：UI/交互/性能修复

#### 1. 视频检测 UI（P0）
- **问题**：VideoView 无缩放模式（不居中）；没有视频播放进度条
- **涉及文件**：`VideoDetectActivity.kt`
- **修复方案**：
  - 为 VideoView 添加居中自适应缩放（ScaleType.FIT_CENTER）
  - 添加 SeekBar 进度条，可控制视频播放时间点
  - 绑定 MediaPlayer 的 currentPosition 更新 SeekBar

#### 2. pt 弹窗（P0）
- **问题**：添加 *.pt 文件时弹窗无"导入"按钮，只有"复制命令"/"分享文件"/"取消"
- **涉及文件**：检查 SettingsActivity 或相关弹窗组件
- **修复方案**：
  - 添加"导入"按钮
  - 实现 pt 文件复制到 assets 目录的功能

#### 3. OkHttpClient 单例化（P0）
- **问题**：每次请求都创建新的 OkHttpClient 实例，浪费资源
- **涉及文件**：网络请求相关类
- **修复方案**：
  - 改为 companion object 单例模式
  - 统一配置超时、拦截器

#### 4. SlidingWindowTracker 内存泄漏（P1）
- **问题**：SlidingWindowTracker 持续增长不释放
- **修复方案**：在 `add()` 路径中添加 `cleanup()` 调用

#### 5. CustomToast 泄漏（P1）
- **问题**：CustomToast 持有 Activity 引用导致泄漏
- **修复方案**：使用 applicationContext 替代 Activity context

#### 6. 主线程阻塞（P1）
- **问题**：存在主线程执行耗时操作
- **修复方案**：异步化耗时操作（协程/线程池）

#### 7. 深色模式（P1）
- **问题**：完全缺失深色模式支持
- **修复方案**：创建 `values-night/` 资源文件，适配 Material Design 深色主题

### 板块三：AI 参数控制

#### 8. 思考开关（P0）
- **问题**：AI 模型参数控制仅适配 Anthropic 格式，DeepSeek/Qwen 需不同参数
- **涉及文件**：AI 模型管理器相关类
- **修复方案**：
  - 新增 UI 开关（Switch/CheckBox）控制是否深度思考
  - 统一适配不同 AI 提供商的思考参数：
    - Anthropic: `thinking.type: "enabled"`
    - DeepSeek: `reasoning_effort`
    - Qwen: `enable_thinking`

### 板块四：训练程序增强

#### 9. 模型转换工具（P1）
- **问题**：缺少统一的 pt→NCNN 转换工具
- **修复方案**：整合 `model_converter.py`，含推理验证+批量处理

#### 10. 蒸馏模式（P2）
- **问题**：`--teacher` 参数仅声明未实现
- **修复方案**：3 阶段实施：基础蒸馏→自定义损失→剪枝量化
