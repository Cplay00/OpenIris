## Mencius (APP 推理侧) 完成情况

### 验证报告

| 验证项 | 结论 | 说明 |
|--------|------|------|
| **V1: decoded 分支坐标空间** | ⚠️ 需实测确认 | 代码逻辑自洽，坐标空间取决于 ultralytics 导出版本 |
| **V2: NMS 兼容性** | ✅ 通过 | 坐标变换数学正确；class-agnostic NMS 对单类无影响 |
| **V3: 标签一致性** | ✅ 通过 | 两端路径一致；行级处理有微小差异（trim vs 不 trim） |
| **V4: 内置模型回归** | ✅ 通过 | 144 < 65 = false，正确走 DFL 分支 |
| **V5: 标签修复** | ✅ 无需修复 | fallback 链已足够健壮 |
| **V6: JNI 内存管理** | ✅ 通过 | 无泄漏 |

### 关键发现

1. **V1 坐标空间**: 需要实测确认。如果坐标是归一化的 (0~1)，需要在 decoded 分支中乘以 target_size
2. **V2 Class-Agnostic NMS**: 当前 NMS 不区分类别，对单类无影响，对多类有轻微影响（低优先级）
3. **V3 行级处理差异**: C++ 不 trim 尾部空白，Kotlin trim。实际影响极小

### 结论
**当前代码不需要修改，但 V1 坐标空间需实测确认。**
